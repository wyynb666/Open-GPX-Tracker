## 二、项目改进与核心功能

本项目旨在解决户外运动者在无网络或弱网环境下的轨迹记录与管理痛点。主要完成的功能模块及代码改进点如下：

### 1. 核心轨迹记录引擎（Core Tracking）

- **高精度记录：** 利用 CoreLocation 框架，实现了基于距离过滤和精度过滤的 GPS 数据采集算法，有效去除了静止时的“漂移点”。

- **实时渲染：** 重写了地图渲染逻辑，使用 MapKit 的 MKPolyline 进行实时轨迹绘制，并实现了随着用户移动自动调整地图视野的功能。

### 2. 数据持久化与文件管理（Data & IO）

- **Core Data 与 GPX 双重存储：** 设计了 `CoreDataHelper` 类，在应用运行时使用 Core Data 高效读写海量轨迹点，在保存时自动序列化为标准的 XML 格式（`.gpx` 文件）并存储在用户的文件管理系统中，确保数据的通用性。

- **文件系统管理：** 实现了完整的沙盒文件管理功能，支持文件的重命名、删除、导出以及从外部应用（如微信、邮件）导入 GPX 文件。

### 3. Apple Watch 扩展

- **独立记录模式：** 利用手表的独立 GPS 芯片，实现了脱离手机的轨迹记录功能。

- **数据同步机制：** 基于 WatchConnectivity 框架，编写了文件传输逻辑，支持在手机与手表重连后，自动将手表端的离线轨迹同步回手机端进行合并归档。

### 4. 数据分析与可视化

- **多维度统计：** 实现了对轨迹数据的实时计算，包括总距离、平均速度、海拔爬升等关键指标。

- **交互式图表：** 开发了轨迹详情页，支持在地图上回放历史轨迹，并查看自定义添加的航点。

## 三、后端/应用程序开发说明

### 1. 开发语言

本项目为纯客户端应用程序，不依赖传统的 Web 后端服务器，所有逻辑均在本地运行以确保离线可用性。

- **主要开发语言：** Swift
- **UI 框架：** UIKit（主框架）+ SwiftUI（部分视图）

源程序文件共计 **55 个**，里面包含了 47 个核心 Swift 代码文件（`.swift`）、2 个应用配置信息文件（`Info.plist`）以及 6 个工程文件（`.xcodeproj`）。

- **控制器（Controller）：** 12 个

整个源代码结构精简高效，未引入臃肿的第三方庞大框架，所有核心逻辑（包括 GPX 解析、数据库操作、手表通信）均由 Swift 原生代码编写实现，文件数量控制在合理范围内，符合实训要求。
